As Mitch Cohen has pointed out, this is *almost* Schur's theorem from Ramsey theory. Noting that the color of $0$ does not matter, this is Schur's theorem from Ramsey theory with the added condition that the triple $a,b,a+b$ must have $a<b$. While the result doesn't follow immediately from Schur's theorem, the proof can be modified for a proof of this problem.

A statement of Schur's theorem is that for any $n$-coloring of $\mathbb{Z}^{+}$, there exists $a,b \in \mathbb{Z}^{+}$ such that $a,b,a+b$ all have the same color. There is a proof [here](https://en.wikibooks.org/wiki/Combinatorics/Schur%27s_Theorem). We can modify this proof to work for this problem as follows:

Suppose we have an $n$-coloring that satisfies the conditions. Let $S=R(4, \dots, 4)$ be the Ramsey number on $n$ colors. We follow the same construction as in the proof above, taking the complete graph on $S$ vertices labelled $\{ 1, \dots, S \}$, with an edge $(i,j)$ given the color for $| i-j |$. By choice of $S$, we have a monochromatic $4$-clique, the vertices of which we denote $i>j>k>l$. Then I claim either $(i-j,j-k,i-k)$ or $(i-j,j-l,i-l)$ is a triple violating the conditions. Otherwise, we have $j-k=i-j=j-l$, which would imply $k=l$, a contradiction. Hence, such an $n$-coloring cannot exist.
